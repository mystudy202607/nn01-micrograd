    bias 偏置神经元中与输入无关的可学习常数项，用来平移激活函数的输出。
    binary classifier 二分类器将输入分为两个类别的模型。

    graph 计算图由变量和运算节点组成的有向无环图，记录计算过程并支持反向传播。
    hidden layer 隐藏层位于输入层和输出层之间的网络层，用来学习中间的特征表示。
    layer 层一组独立计算的神经元，通常将同一维度的输入映射到多个输出。
    leaf node 叶子节点计算图中没有输入边的节点，通常代表输入变量或可训练参数。
    mlp 多层感知机由多个全连接层堆叠而成的前馈神经网络。
    multi layer perceptron 多层感知机由多个线性层与非线性激活函数堆叠而成的前馈神经网络，也常称为 MLP。
    multi-layer perceptron 多层感知机由多个全连接层堆叠而成的前馈神经网络，是最基础的深度网络结构。
    multilayer perceptron 多层感知机由若干全连接神经元层依次堆叠而成的前馈神经网络。
    neural net 神经网络由多层可学习参数组成的函数逼近器，用于从输入预测输出。
    neural network 神经网络由多层神经元组成、通过权重和激活函数对输入进行非线性变换的数学模型。

    node 节点计算图中的基本单元，表示一个值或一次运算。
    non-linearity 非线性神经网络中使模型能拟合复杂函数的弯曲变换。
    output node 输出节点计算图中最终产生输出的节点。
    parameter tensors 参数张量模型中参与训练、需要计算梯度的张量。
    parameters 参数神经网络中可学习的变量，例如权重和偏置，训练时通过梯度更新。
    plus node 加法节点计算图中执行加法运算的节点，其局部导数对该节点的每个输入均为 1。
    relu ReLU修正线性单元激活函数，负值置零，正值保持不变。
    scalar inputs 标量输入单个数值形式的输入，而不是向量或张量。
    tensor 张量多维数组，是深度学习框架中组织标量并进行高效并行运算的基本数据结构。

    weights and biases 权重与偏置神经网络线性层的可学习参数，权重控制输入的影响强度，偏置提供平移。

    反向传播与梯度 28

    _backward 反向传播函数Value 上保存的函数，负责把当前节点的梯度按链式法则传给输入。
    _prev 前驱集合当前值所依赖的子节点集合，反向传播时沿该集合向上追溯。
    accumulate gradients 梯度累加当同一变量被多次使用时，把不同路径回传的梯度相加而不是覆盖。
    autograd 自动求导自动计算梯度的机制，会记录前向计算图并支持反向传播。
    autograd engine 自动微分引擎能够根据计算图自动计算表达式中各变量梯度的引擎。
    back propagation 反向传播利用链式法则从输出向输入高效计算损失函数梯度的算法。
    backprop 反向传播从损失函数出发，沿计算图反向逐节点应用链式法则来计算梯度的算法。
    backpropagate 反向传播利用链式法则从输出端向输入端逐层计算梯度，从而高效地训练神经网络。
    backpropagating signal 反向传播信号在计算图中从输出向输入反向传递的梯度信息，用来按链式法则计算各节点的导数。
    backpropagation 反向传播从输出节点开始，沿计算图反向递归应用链式法则，计算每个中间节点和输入对输出的导数。
    backward 反向传播从输出向输入传播梯度，利用链式法则计算每个变量的梯度。
    backward function 反向传播函数自动计算梯度并沿计算图反向传播的函数。
    backward kernel 反向核函数深度学习框架中实现某个算子反向传播计算的具体底层函数。
    backward pass 反向传播从输出节点向输入节点反向遍历计算图，并计算各变量梯度的过程。
    children 子节点产生当前值的输入值集合，用来建立计算图中的连接关系。
    computational graph 计算图由节点和边组成、表示数值计算依赖关系的有向图。
    differentiate 求导计算函数导数的过程，在反向传播中用于得到梯度。
    differentiate through a function composition 对复合函数求导沿着复合函数由外到内的路径逐层求导，并把各层导数相乘。
    expression graph 表达式图由运算节点和输入变量组成的数学表达式图，用于描述计算过程。
    global derivative 全局导数最终输出对某个中间值的导数，反向传播中体现为该节点累积的梯度。
    grad 梯度计算图中某个变量累积的导数，表示最终输出对该变量的敏感度。
    gradient 梯度损失函数对参数的变化率，指示参数应朝哪个方向调整以降低损失。
    gradient check 梯度检查通过比较数值梯度和反向传播得到的解析梯度来验证实现是否正确的方法。
    gradient vector 梯度向量由损失对所有参数的偏导数组成的向量，指向损失上升最快的方向。
    local derivative 局部导数计算图中某个运算节点对其直接输出变量的导数，不涉及图的其他部分。
    local gradient 局部梯度某个运算节点对其输入变量的导数，只由该节点自身的运算决定。
    propagate 传播梯度沿计算图从输出向输入传递的过程。
    times node 乘法节点计算图中执行乘法的节点，某个输入的梯度等于另一输入的数据乘以输出梯度。

    multivariate chain rule 多元链式法则链式法则在多变量或多路径情形下的推广，需要把各条路径的梯度贡献相加。

    power function 幂函数计算某个数或 Value 的整数/浮点数次方的函数。
    power rule 幂法则求导法则：x 的 n 次方的导数为 n 乘以 x 的 n-1 次方。
    quadratic 二次函数最高次为二次的函数，图像为抛物线，例如 3x² - 4x + 5。
    rate 变化率一个量随另一个量变化而变化的快慢。
    rise over run 纵向变化除以横向变化用两点间 Δy/Δx 近似斜率，是导数的数值计算起点。
    scalar 标量单个数值，区别于向量、矩阵或更高维张量。
    scalar valued 标量值只有大小没有方向的数值，区别于向量和张量。
    scalar-valued function 标量值函数输入和输出都是单个标量（实数）的函数。
    sensitivity 敏感度函数输出对输入微小变化的响应程度，在单变量中与导数直接相关。
    sign of the derivative 导数的符号表示函数随输入增大而增大还是减小。
    slope 斜率函数图像在某一点切线的倾斜程度，数值上等于该点的导数。

    训练与优化 23

    batch 批次训练时一次前向和反向传播所使用的样本子集，通常从数据集中随机抽取。
    bfloat16 bfloat16一种16位浮点数格式，保留与FP32相同的指数范围但降低尾数精度，常用于加速训练。
    binary cross entropy 二元交叉熵针对二分类任务的损失函数，衡量预测概率分布与真实标签之间的差异。
    converge 收敛训练过程中损失逐渐趋于稳定、不再明显下降的状态。
    cross entropy loss 交叉熵损失用于分类任务的损失函数，衡量预测概率分布与真实分布的差异。
    explode the loss 损失爆炸训练中损失值急剧增大到无穷或 NaN，通常由学习率过大或梯度爆炸引起。
    gradient accumulation 梯度累积多次反向传播得到的梯度被累加到同一份参数梯度上而不清零，等效于放大了更新步长。
    gradient descent 梯度下降沿负梯度方向逐步更新参数以最小化损失的优化算法。
    ground truth 真实标签数据中作为正确答案的目标值，用来监督模型训练。
    l2 regularization L2 正则化在损失中加入权重平方和的惩罚项，抑制权重过大，从而缓解过拟合。
    learning rate 学习率控制每次参数更新步长大小的超参数，过大会导致训练不稳定。
    learning rate decay 学习率衰减训练过程中按迭代次数逐步降低学习率的策略，使训练后期更稳定、收敛更精细。
    loss 损失衡量模型预测与目标差距的单一数值，训练时通常希望它越小越好。
    loss function 损失函数衡量模型预测与目标之间差异、训练中需要最小化的函数。
    loss function l 损失函数 L衡量模型预测与真实标签之间差距的函数，训练目标是最小化它。
    mean squared error 均方误差把预测值与真实值之差平方后取平均得到的常用损失。
    minimize the loss 最小化损失通过调整模型参数使损失数值尽可能小。
    overfitting 过拟合模型在训练数据上表现很好但在新数据上变差的现象，通常因模型过于复杂或数据太少。
    re-initialize network 重新初始化网络重新创建网络对象，使新的类定义或参数初始化生效。
    stochastic gradient descent 随机梯度下降一种优化算法，每次使用一小批数据计算梯度并更新参数。
    targets 目标值训练样本中希望模型输出接近的真实标签或期望值。
    zero grad 梯度清零在反向传播前将所有参数的梯度重置为零，防止梯度累加。
    zero_grad 梯度清零PyTorch 中用于将模型参数的梯度置零的方法，通常在反向传播前调用，避免梯度累积。
